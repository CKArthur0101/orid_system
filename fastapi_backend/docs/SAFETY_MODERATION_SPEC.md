# ORID 學生文字安全分類規格

## 目的

安全分類獨立於 ORID、SEL、整合寫作 rubric 與徽章。安全事件不參與學習成效評分。

## 分層流程

1. 本地高精準規則先處理明確粗話、針對性攻擊、威脅與第一人稱危機訊號。
2. 未命中本地規則時，使用 `omni-moderation-latest` 補充語意分類。
3. 依風險等級執行對應動作；被攔截的文字不進入一般 AI 寫作回饋。
4. 模型回覆在顯示前使用相同分類器檢查；若異常則改用固定的安全引導。
5. 非正常事件寫入 `orid_safety_events`；不重複保存學生原文，只保存 SHA-256 指紋與分類資料。

## 五級分類與四種動作

| 等級 | 類型 | 動作 |
| --- | --- | --- |
| 0 | 正常內容 | `allow` |
| 1 | 不雅或羞辱用語 | `coach_rephrase` |
| 2 | 針對他人的人身攻擊 | `block_and_rewrite` |
| 3 | 威脅、仇恨、露骨或其他高風險內容 | `block_and_rewrite` |
| 4 | 自傷或危機訊號 | `support_and_escalate` |

## 語境邊界

- `樹幹`、`幹部`、`操場`、`體操`、`操作`與環境教育中的`垃圾`不得因單字包含而被攔截。
- 兒童繪本可能描述衝突；單純 `violence` 不在寫作回饋路徑自動封鎖。
- `violence/graphic`、威脅性騷擾與仇恨威脅仍屬第 3 級。
- 第一人稱自傷意圖使用支持性訊息，不使用責備式的「不適合送出」。

## 可用性與隱私

- Moderation 暫時失敗時採 fail-open，但仍保留本地高精準規則。
- 安全事件保存使用者、session、週次、階段、分類、動作、提供者與文字指紋；不在事件表複製學生原文。
- 高風險事件寫入伺服器日誌；第 4 級使用 error 等級，其餘使用 warning。
- 教師班級總覽顯示每位學生的安全事件數；第 3～4 級另以高風險提醒標示，但不直接顯示敏感原文。

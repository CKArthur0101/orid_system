# RASF 評量對準單点引導 — 計分與引導規格

> 版本：v2.0（2026-07）  
> 對應 prompt 版本：`wf_v9`、`fn_v9`  
> Rubric：`writing_rubric_v1` v4 + `sel_rubric_v1` v2（CASEL 五面向）

---

## 一、設計原則

**RASF（Rubric-Aligned Single-Focus Feedback）**：每次「取得回饋」只對準 1 個 ORID 向度、估目前層級、指出 1 個缺口、給 1 個下一步。

每次按「取得回饋」（`source: feedback_button`）同時完成三件事：

1. **評分**：估各向度目前層級 → 換算累加分 → 更新總分（研究／教師用）
2. **引導**：ORID 主向度定「從目前階 → 3 達標」的單一缺口；**等級 3／4 → ok=true，不再要求修改**
3. **持久化**：層級與分數寫入 `orid_writing_v1` JSON，跨段累加

**獎章**改為 ORID 歷程達標（見第七節），**不再**用總分 30／60／90 解鎖。

---

## 二、計分公式：層級累加制

每個向度到達第 n 階，代表 1 至 n 階全部達成，分數為三角數：

| 層級 | 中文 | 學生帶 | 分數 | 公式 |
|------|------|--------|------|------|
| 1 | 起步 | 開始寫 | 1 | 1 |
| 2 | 接近 | 差一點 | 3 | 1+2 |
| 3 | 達標 | 不錯 | 6 | 1+2+3 |
| 4 | 精進 | 很好 | 10 | 1+2+3+4 |

**通用公式**：`score(n) = n × (n + 1) ÷ 2`（各向度最高 10 分）

### 各向度與滿分

| 類別 | 向度代號 | 在哪段評 | 滿分 |
|------|----------|----------|------|
| ORID | O1 客觀事實 | O | 10 |
| ORID | R1 感受反應 | R | 10 |
| ORID | I1 詮釋意義 | I | 10 |
| ORID | D1 行動決定 | D | 10 |
| SEL | SEL_SA 自我覺察 | R | 10 |
| SEL | SEL_SM 自我管理 | R／D | 10 |
| SEL | SEL_SOA 社會覺察 | R／I | 10 |
| SEL | SEL_RS 人際技巧 | I／D | 10 |
| SEL | SEL_RD 負責任的決定 | D | 10 |

- **ORID 小計**：O1+R1+I1+D1 = **最高 40 分**
- **SEL 小計**：5 向度 = **最高 50 分**（同 ID 跨段取較高層級）
- **總分**：**最高 90 分**（顯示／研究用；**不**驅動獎章）
- **ok 規則**：僅依 ORID 主向度 ≥ 3（達標）；SEL 不決定 `feedback_ok`
- 舊 ID 別名：`SEL_EA→SEL_SA`、`SEL_PT*→SEL_SOA`、`SEL_RA→SEL_RD`；`SEL_VR` 併入 I1，不再計 SEL 分

## 三、各段一次回饋評哪些向度

| 寫作段 | ORID（必評） | SEL（同次估層級） | 本次最多新增分數 |
|--------|--------------|-------------------|-----------------|
| O | O1 | — | 最多 10 |
| R | R1 | SEL_SA、SEL_SOA、SEL_SM | 最多 40 |
| I | I1 | SEL_SOA、SEL_RS | 最多 30 |
| D | D1 | SEL_RD、SEL_SM、SEL_RS | 最多 40 |

AI JSON 輸出格式（`rubric_level_estimate` 為物件）：

```json
// O 段範例
{
  "rubric_focus": "O1",
  "rubric_level_estimate": { "O1": "2 接近" }
}

// R 段範例
{
  "rubric_focus": "R1",
  "rubric_level_estimate": {
    "R1": "2 接近",
    "SEL_SA": "3 達標",
    "SEL_SOA": "2 接近",
    "SEL_SM": "1 起步"
  }
}
```

## 四、引導規則（RASF 核心）

| 步驟 | 規則 |
|------|------|
| 估層級 | AI 估 ORID 主向度目前在第幾階（1–4） |
| 確定目標 | 目標 = 3 達標；已達 3／4 則完成，不再引導精進 |
| missing | 只對 ORID 主向度，說「從目前階 → 3 達標」的單一缺口（一刀） |
| suggestions | 一個問句或一個填空支架，補 ORID 缺口 |
| SEL | 只估層級、不寫 missing；可讓 suggestions 問句更具體 |
| ok | ORID 主向度 ≥ 3 → true；否則 → false（書本 grounding 問題另計） |
| 學生用語 | 不要說 SEL／自我覺察等術語；改成具體問題 |

### 敘述層（三段回饋）白話結構

- **第一段（你已經做到）**：稱讚學生草稿裡已有的能力（對準 ORID 目前層）
- **第二段（你可以再加強）**：「你已經有 ○○，再補一句 △△ 會更完整」（不寫數字層級標籤）
- **第三段（試試看這樣寫）**：對準 ORID 缺口的一個問句 + 填空支架

## 五、累加計分範例

學生完成 O → R 兩段，層級如下：

| 向度 | 層級 | 分數 |
|------|------|------|
| O1 | 3 達標 | 6 |
| R1 | 2 接近 | 3 |
| SEL_SA | 2 接近 | 3 |
| SEL_SOA | 1 起步 | 1 |

**目前總分 = 6 + 3 + 3 + 1 = 13 / 90**（I、D 與其餘 SEL 尚未回饋為 0）

## 六、論文引用建議

> 本系統採**層級累加計分**（triangular cumulative scoring）：達成第 k 階者，該向度得分為 1 至 k 的累加（k=2 時為 3 分，k=3 時為 6 分）。ORID 四段各有對應主向度，SEL 採 CASEL 五面向輔助計分但不決定引導主題與 `feedback_ok`。AI 回饋（RASF）針對**目前層級至 3 達標**的單一缺口引導；達標後停止修改建議。獎章依 ORID 歷程進度解鎖，與總分門檻脫鉤。

---

## 七、獎章（歷程達標）

Badge ID 維持 `badge_start`／`badge_30`／`badge_60`／`badge_90`（資料庫與圖檔相容），解鎖條件改為：

| Badge ID | 名稱 | 解鎖條件 |
|----------|------|----------|
| badge_start | 下筆徽章 | 有寫作內容 + 使用過回饋或提示 |
| badge_30 | 松果銅徽章 | O 達標（實驗組：`feedback.ok`；對照組：該段有內容） |
| badge_60 | 松果銀徽章 | O + R + I 達標 |
| badge_90 | 松果金徽章 | O + R + I + D 達標 |

---

## 八、對照組差異

對照組仍給固定／模板式提示，不跑 genai RASF 敘述；獎章以「該段已有寫作內容」視為階段完成。實驗組以 `feedback.ok`（ORID ≥ 3）視為階段完成。

# D 段正式實驗前模擬測試

## 測試目的

確認系統不是只認固定句型，而是依每本書的 D1 rubric 判斷學生提出的行動；未達標時，引導學生修改後應至少達到第 3 級。

## 測試條件

1. 使用和正式實驗相同的學生帳號、書籍、週次、AI 組別與正式站網址。
2. 部署後記錄版本與測試日期；測試期間不要再修改提示或程式。
3. 每個案例使用新的寫作工作階段，避免前一題對話影響下一題。
4. 只輸入表內學生原句，不向系統透露預期等級。
5. 將案例順序打亂；截圖並記錄輸入、三段回饋、是否完成、rubric 等級與回應時間。
6. 未達標案例收到引導後，依照引導自行補一句，再於同一工作階段送出修改稿。
7. 同一句不要靠清快取重複測；變異性檢查要開新工作階段，並保留每一次結果。

## 第二輪：引導後閉環

對 A1、A2、B1、B2、B5、C1、C2 執行：

1. 先送出原句，確認系統只指出一個真正缺項。
2. 不照抄系統答案，只依它的問題補寫自己的想法。
3. 再次送出修改稿。
4. 修改稿若已符合該書 D1 第 3 級，系統必須停止追問並判定完成。

閉環失敗包含：引導內容無法照做、照做後仍被問同一件事、增加 rubric 未要求的條件、或直接代寫完整答案。

## 第三輪：穩定性

將 A2、A4、B2、B4、B5、C2、C4 各用三個新工作階段重跑。文字保持完全相同，檢查判斷是否一致。回饋措辭可以不同，但通過／不通過與指出的核心缺項應一致。

## 通過門檻

- 明顯空願望不得誤判通過。
- 所有第 3 級案例不得因固定詞語或陌生動作而誤擋。
- 與書籍 D1 明定主題不符的案例不得誤判通過。
- 每次只給一個修改方向，不代寫完整答案。
- 學生依引導完成修改後，符合第 3 級者必須通過。
- 同一案例三次重跑的通過判斷必須一致；若不一致，先記錄為模型穩定性問題，不用新增動詞詞表修補。
